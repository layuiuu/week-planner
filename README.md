# 周计划

**线上地址(手机直接打开):https://layuiuu.github.io/week-planner/**

打开后点浏览器的「添加到主屏幕」,就当成 App 用。数据只存在你自己手机/电脑的浏览器里,这个网址上没有任何你的个人信息。

---

一个纯静态的网页小工具:把每周固定的时间表变成**每周框架**,再把每天要做的具体任务**挂到框架的板块里**,一眼看到整周安排,勾选完成、按周复盘。

- 手机浏览器打开就能用,「添加到主屏幕」后和 App 差不多。
- 数据**只存在你自己这台设备的浏览器里**(localStorage),不注册、不登录、不上传服务器。
- 零依赖、零构建:没有任何第三方库,不需要 `npm install`,不需要打包。放到 GitHub Pages 上就能跑。

## 三步走

1. **导入周表** → 生成每周框架
   上传一张 Excel(.xlsx)或 CSV,表头固定:

   | 星期 | 板块名称 | 类别 | 开始 | 结束 |
   | --- | --- | --- | --- | --- |
   | 周一 | 上午学习 | 学习 | 09:00 | 12:00 |
   | 周一 | 下午工作 | 工作 | 14:00 | 16:00 |

   一个**板块** = 一段时间 + 一个类别 + 一个名字。星期写成「周一 / 星期一 / 一 / 1」都认;时间写成 `09:00`(Excel 里直接填时间也可以)。

2. **导入任务清单** → 任务挂到板块上

   | 日期 | 板块名称 | 任务 | 备注 |
   | --- | --- | --- | --- |
   | 2026-10-12 | 上午学习 | 复习第三章 | 重点看例题 |
   | 2026-10-12 | 下午工作 | 写周报 | 周五交 |

   日期写 `2026-10-12`(Excel 里的日期格式也认);「板块名称」要和周表里写的一模一样。

3. **看 · 勾 · 复盘**
   - **周历**:手机上一列显示选中的那一天,屏幕宽时并排 7 列看整周。每条任务都能勾选完成、写备注。
   - **看板**:按类别把任务分组,方便看推进。
   - **复盘**:回看任意一周的整体完成率、每个类别/板块的完成情况、每天未完成的项目,并写复盘备注。

导入之前都会先给你一个**确认页**:上面列清楚将写入哪些内容、哪些行读不了、哪些任务找不到对应板块。确认了才会真的存进去。

## 文件格式要求

只要**两个文件**:周表 + 任务表。都是固定表头,系统照着读,不做任何猜测。表头行不一定要在第一行,但必须有一行写着这些表头,系统会自动找到它。

> 最省事的做法:**别自己建表,直接下载模板**(应用里 → 设置 →「周表模板 .xlsx / 任务模板 .xlsx」,或仓库 `samples/` 目录),照着示例改。

### 周表(生成每周框架)

| 列 | 必填 | 怎么填 |
| --- | --- | --- |
| **星期** | ✅ | `周一` / `星期一` / `礼拜一` / `一` / `1` 都认;英文 `Mon`、`Monday` 也认 |
| **板块名称** | ✅ | 这段时间叫什么,例如 `上午学习`。任务表靠这个名字对上板块。**同一个星期内不能重名**;不同星期可以同名(每天都有「上午学习」是正常的) |
| **类别** | ✅ | 用来分组和统计,例如 `学习` / `工作` / `健身` / `生活`。留空算「未分类」 |
| **开始** | ✅ | `09:00` 或 `9:00`;Excel 里的时间单元格也认 |
| **结束** | ⬜ | 不填就只显示开始时间。结束早于开始只会**提醒**,不会被拒 |

一个**板块** = 一段时间 + 一个类别 + 一个名字。示例:

```
星期 | 板块名称 | 类别 | 开始  | 结束
周一 | 上午学习 | 学习 | 09:00 | 12:00
周一 | 下午工作 | 工作 | 14:00 | 16:00
周三 | 夜跑     | 健身 | 19:00 | 20:30
```

### 任务表(把每天的事挂到板块上)

| 列 | 必填 | 怎么填 |
| --- | --- | --- |
| **日期** | ✅ | `2026-10-13`、`2026/10/13`、`2026年10月13日`、Excel 日期单元格都认;只写 `10-13` 会补当前年份(确认页会显示解析结果) |
| **板块名称** | ✅ | 要和周表里**那一天的**板块名一字不差。对不上不会丢,会被放进「未匹配板块」并提示那天有哪些板块可用 |
| **任务** | ✅ | 要做的事 |
| **备注** | ⬜ | 导入后还能在应用里随时改 |

```
日期       | 板块名称 | 任务        | 备注
2026-10-12 | 上午学习 | 复习第三章  | 重点看例题
2026-10-12 | 下午工作 | 写周报      | 周五交
```

### 通用规则

- **表头可以用别名**,例如「开始时间」「Start Time」「任务内容」;空格、大小写、全角半角、括号里的说明都不影响识别。
- **多出来的列**会被忽略(并提醒你),**空行**自动跳过。
- 同一天 + 同一板块 + 同样内容的任务算**重复**,默认跳过(可在确认页取消勾选强行导入)。
- Excel 文件有**多张工作表**时,系统挑表头最像的那张,并在确认页告诉你是哪张。
- 支持 **`.xlsx` / `.xlsm` / CSV**;老版 `.xls` 请在 Excel 里另存为 `.xlsx` 或 CSV。
- CSV 编码**自动识别**,UTF-8 和中文 Windows 的 GBK 都不会乱码(Excel 直接「另存为 CSV」也读得进来)。

## 放的规则(几个关键决定)

- **板块 = 时间段 + 类别 + 名称**,三者都参与划分。
- **周框架默认套用**:只维护一份模板,任何一周打开都自动套用同一套板块。某一周要临时调整(加一个、删一个、改时间),用「编辑本周板块」——**只影响那一周**,模板不动。
- **任务状态两档**:未完成 / 完成,一个勾选框。
- **历史按日期累积**:每周是独立的一份记录,可以回看以前任意一周。
- **备注**:每条任务可以写备注;每天有当天备注;每个板块每周有板块备注;每周有复盘备注。
- 不需要 AI 猜内容、不需要账号、不需要云同步、不需要「目标/阶段」体系。

## 部署到 GitHub Pages

这个仓库已经部署好了(见页面顶部的线上地址)。下面是**自己重新部署 / 换账号**的做法。

### 方式一:用项目里的部署脚本(推荐,尤其在国内)

这台机器上 `github.com` 的 443 端口被网络挡住了,`git push` 会超时,但 `api.github.com` 能通。所以用脚本走 API:

```bash
cd 这个文件夹
python tools/deploy.py            # 默认发布到 week-planner 仓库
python tools/deploy.py 别的名字    # 想换仓库名
```

脚本会:读本机 Git Credential Manager 里已存的 GitHub 凭据 → 建仓库(没有就建,公开)→ 一次性提交全部文件 → 开启/更新 GitHub Pages → 等构建完成并打印网址。**改完代码再跑一次就是更新线上。**

### 方式二:常规 git push(网络没问题时)

```bash
cd 这个文件夹
git init
git add .
git commit -m "周计划"
git branch -M main
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

然后:仓库 **Settings → Pages → Source 选「Deploy from a branch」**,分支选 `main`、目录选 `/(root)`,保存。等一两分钟,访问:

```
https://<你的用户名>.github.io/<仓库名>/
```

手机浏览器打开这个网址 → 菜单里的「添加到主屏幕」→ 之后就像 App 一样用,离线也能打开(Service Worker 会缓存应用外壳)。

不需要 Jekyll 处理,仓库里已放了 `.nojekyll`。

### 本地预览

项目用的是 ES Module(浏览器安全限制),**双击 `index.html`(file://)打不开**,需要用一个网址访问:

```bash
cd 这个文件夹
python -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```

## 界面风格

iOS 风格。改样式只需要动 `css/styles.css`——颜色、圆角、投影、毛玻璃都在文件开头的 `:root` 变量里。

- 页面底 `#F2F2F7`(暗色 `#000`),卡片纯白(`#1C1C1E`);卡片用**极淡投影分层**(`0 2px 8px rgba(0,0,0,.05)`),**不用边框**勾勒
- 卡片 / 按钮统一 **14px 圆角**;**底部导航是 40px 悬浮胶囊**(左右留 16px、离底 22px)
- **毛玻璃只用在悬浮元素**上:`rgba(255,255,255,.85)` + `backdrop-filter: blur(20px)`,包括底部胶囊导航、弹出菜单、周历吸顶导航条
- **类别色是马卡龙色系**:10 色调色板,常见类别(学习/工作/健身/生活/兴趣/阅读…)固定取值保证互不相同,其它按名称稳定取色;小圆点和浅色底都跟随同一个颜色,周历 / 看板 / 复盘三处一致
- **数字统一等宽**(`tabular-nums`),勾选前后不跳动;层级靠字号 + 字重区分
- 周历顶部的周导航 + 日期条**吸顶**,进入页面自动把「当前时段」的板块对齐到顶部并加一圈提示
- 看板默认看**今天**、纵向排列,**按板块折叠**(默认收起);复盘只保留「按板块完成情况」,用紧凑卡片网格,数字右对齐
- 浅色 / 深色两套调色板都按 **WCAG AA** 校过对比度(实测浅色最低 4.76、深色最低 5.27)

## 已知边界

- **只支持 `.xlsx` 和 CSV**,不支持旧版 `.xls`(BIFF 格式太老),请在 Excel 里另存为 `.xlsx` 或 CSV。
- CSV 会自动识别 UTF-8 / GBK(中文 Windows 的 Excel 默认存 GBK),不会乱码。
- 解析 xlsx 用到浏览器的 `DecompressionStream`,需要较新的浏览器(Chrome 80+ / Safari 16.4+ / Edge / Firefox 113+)。万一不支持,把文件另存为 CSV 就能用。
- localStorage 大约 5MB,存日程和任务足够了。但它是**本机独占**、且可能被「清理浏览器数据」清掉,所以设置页一直放着**导出备份(JSON)/ 导入备份**——换手机或清理前记得导出一份。
- 任务靠「板块名称」匹配板块。如果之后在周表里改了某个板块的名字,已有任务会匹配不到,会在「未匹配板块」里单独列出来(不会静默丢掉),点一下就能重新指定。
